# "حسبتك" (Hasebtak) 🇪🇬
### المستشار الرقمي لموازنة المواطن 2026/2027 — وزارة المالية المصرية
**The Digital Advisor for Egypt's Citizen Budget 2026/2027**

> مُعد خصيصاً لـ **مسابقة الابتكار في موازنة المواطن 2026/2027**.  
> منصة محادثة ذكية متكاملة بتكلفة تشغيل **صفر جنيه (0 EGP)**، تم بناؤها لمواجهة التحدي الأكبر في تقرير الموازنة: فجوة المشاركة المجتمعية (**35/100** في مسح الموازنة المفتوحة الدولي OBS 2025).

---

## 🌟 المحاور الثلاثة للمنصة (Three Pillars in One Bot)

1. **اسأل عن فلوسك (Ask About Your Money):**
   - محرك ذكاء اصطناعي تأصيلي (Grounded RAG) يشرح بنود ومصروفات الموازنة بالعامية المصرية البسيطة (نصاً وصوتاً).
   - تخصيص ذكي للإجابات حسب فئة السائل: **طالب 🎓 / موظف 💼 / صاحب مشروع 🏭**.

2. **هل تستحق؟ (Do You Qualify?):**
   - دليل استرشادي حتمي (Deterministic Decision Tree) لبرامج الحماية والدعم الاجتماعي (تكافل وكرامة، بطاقات التموين، التأمين الصحي لغير القادرين، حوافز المشروعات).
   - توجيه مباشر للقنوات الرسمية المعتمدة للتقديم **بدون إصدار أحكام آلية وبدون تخزين أي بيانات شخصية (Zero PII)**.

3. **نبض المواطن (Citizen's Pulse):**
   - استطلاع رأي أسبوعي تفاعلي من ضغطة واحدة عبر واتساب وتليجرام، ينقل آراء وأولويات المواطنين لصناع القرار في وزارة المالية.
   - لوحة تحكم تحليلية مباشرة (Analytics Dashboard) تعزز الشفافية والمشاركة الشعبية.

---

## 🛡️ محرك التأصيل وحاجز الأمان (Grounding Layer)

> **الوعد الجوهري:** *الالتزام التام بالأرقام الرسمية الصادرة عن وزارة المالية، وصفر هلوسة عددية.*

تعتمد المنصة على نظام حماية رباعي الطبقات:
1. **سجل الأرقام المؤكدة (Facts Ledger):** سجل منظم (`data/facts_ledger.json`) يضم كافة أرقام الموازنة الرئيسية ومصادرها بالصفحة من التقرير الرسمي، محصن ضد أخطاء استخراج الـ PDF.
2. **استرجاع السياق النصي (Vector RAG):** فهرس متجهات محلي باستخدام `ChromaDB` لتوفير التفسيرات وسياق المبادرات والإصلاحات.
3. **التوجيه المنضبط (Grounded Prompt):** قالب أوامر صارم بالعامية المصرية يلزم النموذج بالإجابة فقط من السياق المؤكد وذكر المصدر الموثق.
4. **حاجز الأمان الرياضي الحتمي (Deterministic Numeric Guardrail):** معالج يفحص كل رقم في إجابة الذكاء الاصطناعي ويطابقه مع أرقام المصدر؛ فإذا وجد أي رقم غير موثق، يتم حجب الإجابة فوراً وإرجاع رد آمن معتمد.

## 💸 إثبات التكلفة الصفرية (0 EGP)

| المكون | الخدمة / الأداة | مجاني؟ | ملاحظات |
|---|---|---|---|
| **الاستدلال اللغوي (LLM)** | Google Gemini Flash Free Tier | ✅ | 1,500 طلب/يوم بدون بطاقة بنكية |
| **استرجاع المتجهات (Vector DB)** | ChromaDB (Local) | ✅ | مفتوح المصدر ويعمل محلياً |
| **تحويل النص إلى صوت (TTS)** | `edge-tts` (أصوات مصرية طبيعية) | ✅ | مجاني بالكامل (`ar-EG-SalmaNeural`) |
| **القناة المستدامة للأبد** | Telegram Bot API | ✅ | مجاني 100% وبدون أي رسوم رسائل |
| **قناة العرض والتجربة** | WhatsApp Cloud API / Sandbox | ✅ | حساب مطور مجاني |
| **لوحة التحكم والمؤشرات** | Streamlit | ✅ | مفتوح المصدر وتفاعلي |
| **قاعدة بيانات الاستطلاعات** | تخزين JSON محلي مشفر | ✅ | صفر تكلفة وأمان تام |

## 📂 الهيكل التنظيمي للمشروع (Repository Structure)

```
hasebtak/
├── data/
│   ├── facts_ledger.json         # الأرقام المؤكدة المعتمدة (Source of Truth)
│   ├── eligibility_tree.yaml     # شجرة برامج الدعم (هل تستحق؟)
│   ├── poll_bank.json            # بنك استطلاعات نبض المواطن
│   ├── poll_votes.json           # الأصوات المجهولة المشفرة (SHA-256)
│   └── report_narrative_chunks.json # مقاطع التقرير المفهرسة
├── ingestion/
│   ├── extract.py                # استخراج النصوص ومعالجة العربية
│   ├── chunk.py                  # تقطيع النصوص حسب الأقسام والصفحات
│   └── embed_index.py            # بناء وتحديث فهرس ChromaDB
├── core/
│   ├── router.py                 # موجه النوايا والمنسق المركزي
│   ├── grounding.py              # محرك استرجاع الأرقام المؤكدة والمتجهات
│   ├── prompt.py                 # قالب التوجيه الصارم بالعامية المصرية
│   ├── guardrail.py              # حاجز الأمان الحسابي ضد الهلوسة
│   ├── llm.py                    # عميل Gemini Flash مع Fallback
│   ├── voice.py                  # تحويل النصوص إلى صوت مصري طبيعي
│   ├── eligibility.py            # محرك المحور الثاني (دليل الحماية)
│   └── polls.py                  # محرك المحور الثالث (استطلاعات نبض المواطن)
├── channels/
│   ├── base.py                   # واجهة الرسائل المحايدة
│   ├── telegram_adapter.py       # محول تليجرام التفاعلي
│   └── whatsapp_adapter.py       # محول واتساب (Meta Cloud API)
├── dashboard/
│   └── app.py                    # لوحة تحكم Streamlit التفاعلية للمسؤولين
├── tests/
│   ├── eval_questions.json       # 50 سؤالاً تقييمياً شاملاً
│   └── test_accuracy.py          # فحص دقة التأصيل وحاجز الأمان
├── app.py                        # خادم FastAPI الرئيسي ومحاكي الـ CLI
├── requirements.txt              # المتطلبات والمكتبات
├── .env.example                  # نموذج المتغيرات البيئية
└── .gitignore                    # حماية الأسرار والملفات المؤقتة
```

## 🚀 التشغيل السريع (Quickstart)

### 1. إعداد البيئة وتثبيت الحزم
```bash
python -m venv .venv
# على ويندوز:
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية
انسخ ملف `.env.example` إلى `.env` وضع مفتاحك:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. بناء وتحديث فهرس المتجهات (Vector Index)
```bash
python ingestion/embed_index.py
```

### 4. تجربة المحادثة المباشرة عبر الطرفية (CLI Mode)
```bash
python app.py cli
```

### 5. تشغيل لوحة التحكم التفاعلية للمسؤولين (Streamlit Dashboard)
```bash
streamlit run dashboard/app.py
```

### 6. تشغيل خادم الـ Webhook وواجهات برمجة التطبيقات (FastAPI)
```bash
python app.py
```
سيكون الخادم متاحاً عبر: `http://localhost:8000` وواجهة Swagger التفاعلية على: `http://localhost:8000/docs`.

### 7. تشغيل اختبارات الدقة وحاجز الأمان (Evaluation Suite)
```bash
python tests/test_accuracy.py
```

## 🔒 الخصوصية وأمان المعلومات ("آمن معلوماتيًا")

- **Zero PII:** لا يتم طلب أو تخزين أي رقم قومي، أو دخل مالي، أو أرقام هواتف صريحة للمواطنين.
- **التشفير الأحادي:** يتم تشفير معرفات القنوات عبر خوارزمية `SHA-256` مع Salt دوري لضمان سرية التصويت في الاستطلاعات.
- **الحيادية والموثوقية:** دليل الحماية الاجتماعية استرشادي بالكامل مع توضيح فوري أن القرار النهائي يخص اللجان والجهات الرسمية المختصة.
